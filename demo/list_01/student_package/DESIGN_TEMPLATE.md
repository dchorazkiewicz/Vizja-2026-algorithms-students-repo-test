# Algorithm design template

Complete this short design note for each task.

## Problem

What exactly is being computed?

## Precondition

What must be true before the algorithm starts?

## Postcondition

What must be true when the algorithm finishes successfully?

## Side effects

Does the algorithm modify its input or any external state?

## Failure behaviour

What happens when the input violates the accepted domain?

## State meaning

What does each important variable represent during execution?

## Termination

Why must the algorithm terminate?

## Time complexity

What is the input-size measure, what is the important operation, and how does the cost grow?

## Auxiliary space

How much additional memory does the implementation require as the input grows?

## Pseudocode

Describe the algorithm in a language-independent form.
